# Relatório Financeiro com Power BI

Projeto desenvolvido como parte da Formação Power BI Analyst da DIO, utilizando a base Financial Sample do Power BI.

## Objetivo

O objetivo do desafio foi criar um relatório interativo e mais elaborado, utilizando diferentes recursos do Power BI para facilitar a análise dos dados.

## Recursos utilizados

- Power BI Desktop
- Financial Sample
- Cartões de indicadores
- Segmentadores de dados
- Botões de navegação
- Indicadores (Bookmarks)
- Alternância entre diferentes visuais
- Árvore de decomposição
- Gráficos de área, barras, rosca, treemap e cascata

## Página 1 - Sales Report

A primeira página apresenta uma visão geral das vendas, com os principais indicadores e diferentes formas de análise por período, segmento, produto e país.

![Sales Report](images/1print.png)

## Página 2 - Report de Lucro Detalhado

A segunda página apresenta uma análise mais detalhada do lucro, permitindo visualizar os dados por ano, país, produto, segmento e trimestre.

![Report de Lucro Detalhado](images/2print.png)

## Funcionalidades

Foram utilizados botões e indicadores para alternar entre diferentes gráficos sobre o mesmo assunto.

Também foram adicionados segmentadores de dados e botões para navegação entre as páginas do relatório.

## Aprendizados

Durante o desenvolvimento do projeto pratiquei:

- Criação e organização de dashboards
- Utilização de diferentes tipos de gráficos
- Criação de filtros e segmentadores
- Uso de indicadores e botões
- Navegação entre páginas
- Organização visual das informações

## Fonte dos dados

Os dados utilizados são da base Financial Sample disponibilizada no desafio.
